# Unit 3B Task 2 — Example solution

Demonstrate tuple concatenation, slicing, and unpacking.

```python
# Example solution: tuple operations
tuple_data = (1, 2, 3)
tuple_extra = (4, 5)

joined = tuple_data + tuple_extra
print("Joined:", joined)

print("Slice first two:", tuple_data[:2])

a, b, c = tuple_data
print("Unpacked:", a, b, c)
```
