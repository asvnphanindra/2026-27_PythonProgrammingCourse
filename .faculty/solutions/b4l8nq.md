# Unit 2D Task 2 — Example solution

Demonstrate common string methods.

```python
# Example solution: string methods
s = "  Hello Python World  "

print("Upper:", s.upper())
print("Lower:", s.lower())
print("Strip:", s.strip())
print("Split:", s.split())
print("Join:", "-".join(["Hello", "Python"]))
print("Replace:", s.replace("Python", "Java"))
print("Find:", s.find("Python"))
```
