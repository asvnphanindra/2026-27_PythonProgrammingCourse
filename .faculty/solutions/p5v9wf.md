# Unit 4A Task 5 — Example solution

Iterate through a dictionary using loops.

```python
# Example solution: iterate dictionary with loops
scores = {"maths": 80, "science": 75, "english": 90}

print("Keys:")
for key in scores:
    print(key)

print("Values:")
for value in scores.values():
    print(value)

print("Items:")
for key, value in scores.items():
    print(key, "→", value)
```
