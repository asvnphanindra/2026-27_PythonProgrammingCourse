# Unit 2D Task 8 — Example solution

Check whether two strings are anagrams.

```python
# Example solution: anagram check
s1 = input("Enter first string: ")
s2 = input("Enter second string: ")

if sorted(s1) == sorted(s2):
    print("Anagrams")
else:
    print("Not anagrams")
```
