# Unit 2D Task 1 — Example solution

Demonstrate string creation and basic operations.

```python
# Example solution: string creation and basic operations
s = "Python"
print("String:", s)

s1 = "Hello"
s2 = "World"
print("Concatenation:", s1 + " " + s2)

print("Repetition:", s * 3)

print("First 3 characters:", s[:3])
print("Last 3 characters:", s[-3:])
print("Characters from index 1 to 4:", s[1:5])
```
