# Unit 3B Task 4 — Example solution

Find the maximum and minimum in a tuple.

```python
# Example solution: max and min in a tuple
tuple_data = (12, 5, 28, 9, 17)

largest = max(tuple_data)
smallest = min(tuple_data)

print("Tuple:", tuple_data)
print("Maximum:", largest)
print("Minimum:", smallest)
```
