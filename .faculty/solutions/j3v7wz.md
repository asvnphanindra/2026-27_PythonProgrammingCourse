# Unit 3A Task 2 — Example solution

Demonstrate list operations: insert, append, remove, sort, reverse.

```python
# Example solution: list operations
list_data = [3, 1, 4, 1, 5]
print("Original:", list_data)

list_data.append(9)
print("After append:", list_data)

list_data.insert(0, 7)
print("After insert:", list_data)

list_data.remove(1)
print("After remove:", list_data)

list_data.sort()
print("After sort:", list_data)

list_data.reverse()
print("After reverse:", list_data)
```
