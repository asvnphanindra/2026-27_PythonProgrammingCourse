# Unit 4A Task 1 — Example solution

Create, access, and update a dictionary.

```python
# Example solution: create, access and update a dictionary
student = {
    "name": "Anu",
    "age": 20,
    "course": "Python",
}
print("Student:", student)
print("Name:", student["name"])

student["age"] = 21
student["city"] = "Guntur"
print("Updated:", student)
```
