# Unit 2C Task 1 — Example solution

Print a square pattern of zeros.

```python
# Example solution: square pattern of zeros
rows = 3

for row_loop_var in range(1, rows + 1):
    for column_loop_var in range(1, rows + 1):
        print(0, end=" ")
    print()
```
