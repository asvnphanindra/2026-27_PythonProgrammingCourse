# Unit 4B Task 1 — Example solution

Demonstrate a try-except block for handling exceptions.

```python
# Example solution: try-except block
try:
    a = 10
    b = 0
    result = a / b
    print("Result:", result)
except ZeroDivisionError:
    print("Cannot divide by zero.")
```
