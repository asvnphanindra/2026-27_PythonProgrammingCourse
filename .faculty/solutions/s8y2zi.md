# Unit 4A Task 8 — Example solution

Merge two dictionaries.

```python
# Example solution: merge two dictionaries
dict1 = {"a": 1, "b": 2}
dict2 = {"b": 3, "c": 4}

merged = {**dict1, **dict2}
print("Merged:", merged)
```
