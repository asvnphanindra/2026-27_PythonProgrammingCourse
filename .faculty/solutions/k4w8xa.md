# Unit 3A Task 3 — Example solution

Find the largest and smallest element in a list.

```python
# Example solution: largest and smallest in a list
list_data = [12, 5, 28, 9, 17]

largest = max(list_data)
smallest = min(list_data)

print("List:", list_data)
print("Largest:", largest)
print("Smallest:", smallest)
```
