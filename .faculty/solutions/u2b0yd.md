# Unit 2C Task 2 — Example solution

Print a 3x3 grid of zeros using nested for loops.

```python
# Example solution: 3x3 grid of zeros
for row_loop_var in range(1, 4):
    for column_loop_var in range(1, 4):
        print(0, end=" ")
    print()
```
