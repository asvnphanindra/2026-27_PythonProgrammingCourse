## Activity-Based Learning (ABL-1)

Select any **10** case studies. For each case, keep **only two files** in one folder:

```text
ActivityBasedLearning-1/
└── Case53-FoodWasteMonitoring/
    ├── food_waste_monitoring.md   ← description
    └── food_waste_monitoring.py   ← program
```

**Description file (`.md`) must include:** Aim, INPUT, PROCESS, OUTPUT, Algorithm, Pseudocode (`BEGIN` … `END`), Flowchart, Sample, Conclusion.

**Flowchart shapes:** Oval = Start/Stop · Parallelogram = Input/Output · Rectangle = Process · Diamond = Decision.  
Do not write the words Input/Process/Output inside boxes. Combine adjacent I/O boxes. Use type-clear names (`int_days`, `float_limit`, `str_day`, `list_high_waste_days`).

**Example:** [Case 53 — Food Waste Monitoring](ActivityBasedLearning-1/Case53-FoodWasteMonitoring/food_waste_monitoring.md)

Upload to your GitHub repo named `Python-Activity-Based-Learning`.
