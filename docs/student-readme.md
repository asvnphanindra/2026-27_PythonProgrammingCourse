# Student README format

Put a `README.md` in the root of your course repository. The Student Progress Dashboard checks these fields, so use the labels below exactly.

## Template

```markdown
# Python Programming Course

- Institution: NRIU
- Academic Year: 2026-27
- Course: Python Programming
- Section: Sec-21
- Serial Number: 1
```

## Rules

- **Institution**, **Academic Year**, **Section**, and **Serial Number** are the fields the dashboard checks. Use those labels (`Serial No` or `S No` also work).
- Section form: `Sec-21` (not `Section 21`).
- Serial number is your **class serial number**, not your university roll number.
- **Do not put your roll number** in the public README.
- Replace `Sec-21` and `1` with your own section and serial number.
- Your repository name should follow: `2026-27_Sec-<section>-<serial>_PythonProgrammingCourse` (example: `2026-27_Sec-21-1_PythonProgrammingCourse`).

## Optional

You may add your name and GitHub username below the metadata block. Those lines are not validated by the dashboard.

```markdown
- Name: Your Name
- GitHub: your-github-username
```
