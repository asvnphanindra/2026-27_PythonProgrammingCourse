<a id="before-lab"></a>

## Before lab — Lab observation

Prepare the lab observation / protocol **before** you come to the lab.

The task list column **Lab observation expectations** shows one of:

| Value | Meaning |
|-------|---------|
| [Full](#full) | Full observation write-up |
| [Short](#short) | Short observation write-up |
| [Will be informed later](#will-be-informed-later) | Faculty will announce later |

<a id="full"></a>

### Full

Prepare all of these:

| Left-hand page | Right-hand page |
|----------------|-----------------|
| Flowchart | Task |
| Pseudocode | Aim |
| Test cases | Algorithm |
| | Python program |
| | Saved file location |

**Test cases:** at least **5** cases; at least **2** must be tricky (edge, boundary, or unusual inputs). For each case write Input, Expected output, and Actual output.

<a id="short"></a>

### Short

Prepare only these:

| Left-hand page | Right-hand page |
|----------------|-----------------|
| Test cases | Task |
| | Aim |
| | Python program |
| | Saved file location |

**Test cases:** at least **5** cases; at least **2** must be tricky. For each case write Input, Expected output, and Actual output.

<a id="will-be-informed-later"></a>

### Will be informed later

Lab observation details for this task will be announced later. Still follow [during lab](#during-lab) and [after lab](#after-lab) when those apply.

## During lab — GitHub code

Upload **fully functional** Python code to your course GitHub repository.

- Use the **exact file name** from the [lab tasks](lab-tasks.md) list
- One task per file
- Follow the [commit message](commit-messages.md) stages
